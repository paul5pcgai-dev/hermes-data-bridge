Independent TikTok API connector for Hermes

Your profile details, account totals, and public videos in Hermes.

Account Data Bridge is a locally run Model Context Protocol (MCP) connector. Each user authorizes their own TikTok account through TikTok’s official Login Kit and Display API. The connector is read-only and requests only user-approved scopes.

Information the authorized scopes provide

Subject to TikTok’s app approval and the permissions an account holder grants, the connector can request:

Basic profile

Account identifier, profile image, and display name (user.info.basic).

Profile details

Username, bio, profile links, and verification status (user.info.profile).

Account statistics

Follower, following, likes, and public-video counts (user.info.stats). These are totals, not lists of people.

Public videos

Public videos posted by the authorized account and video metadata TikTok makes available (video.list).

Limits

These scopes do not provide private videos, direct messages, or individual follower/following lists. They do not authorize posting or uploading videos. The connector does not request those permissions.

Access depends on TikTok approving the app and scopes, and on each user authorizing them. Available fields are limited to what TikTok returns for the granted scopes.

How information is handled

TikTok API results are returned to the user’s active Hermes conversation. The model provider configured for that Hermes session may process the returned information. The connector runs locally and does not maintain a separate service-side database of TikTok content.

Independent project

Account Data Bridge is not affiliated with, endorsed by, or sponsored by TikTok. TikTok and its marks belong to their respective owner.
